# Georgios Karamousalis — Portfolio

Responsive, accessible dark portfolio built with React and Vite. It presents education, engineering skills, professional experience, research, projects, social profiles, downloadable CV and direct contact.

## Local setup

```bash
npm install
npm run dev
```

Production verification:

```bash
npm run build
npm run preview
```

Place `Georgios_Karamousalis_CV.pdf` in `public/` before deployment.

## Highlights

- Semantic single-page structure and keyboard-accessible navigation
- Responsive layouts for desktop, tablet and mobile
- Lightweight styling with no runtime CSS framework
- SEO and theme metadata
- External links use explicit, trusted profile URLs

## Deployment

The generated `dist/` directory can be deployed to GitHub Pages, Netlify, Vercel or any static host.
